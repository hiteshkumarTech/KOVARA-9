# Research questions

The primary question is:

> Can independently learning agents develop useful coordination strategies and generalize those
> strategies to unseen procedural environments?

Supporting questions include:

1. When does limited communication improve exploration efficiency enough to justify its cost?
2. Do agents develop complementary spatial roles without explicit role labels?
3. How robust are learned policies to changed obstacle density, map size, team size, and teammate
   failure?
4. Which training signals improve coordination without encoding a scripted solution?
5. How large is the gap between in-domain performance, held-out seeds, and structural shifts?

Phase 0 does not answer these questions. It provides falsifiable metrics and controlled interfaces
for later experiments.
