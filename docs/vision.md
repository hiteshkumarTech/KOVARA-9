# Project vision

KOVARA-9 asks whether independently learning embodied agents can develop coordination strategies
that remain useful in procedural environments not seen during training.

The v0.1 platform supports partial observability, limited communication, centralized training with
decentralized execution, one MAPPO-style reinforcement-learning path, deterministic checkpointing,
and reproducible generalization studies. The frozen experiment improved partial behaviors but did
not learn complete cooperative task behavior.

Dynamic role formation, failure recovery, imitation learning, and broader coordination mechanisms
remain future research. They will be added only through controlled roadmap decisions after the
simulator, baselines, metrics, and evaluation methodology remain trustworthy.

Phase 0 is intentionally a lightweight two-dimensional foundation suitable for a normal student
laptop. Visual spectacle is not a research deliverable.
